01 // Origin Story & Human Constraints

Turning a Stakeholder Sketch Into a Multi-Generational Tool

01 // FROM PROTOTYPE TO SHIPPABLE PRODUCT

Elevating Chris's Foundation

Chris initiated the vision, wrote the reunion brief, and spun up an initial prototype on his Mac to rescue fading family memories. Rather than starting over, I treated his brief and instincts as the spec—hardening concurrency, ingesting cross-platform uploads, adding audit trails, and making it rock-solid for every relative's phone.

02 // FRICTIONLESS REUNION ACCESS

Simple Name Entry Meets Protected Uploads

Requiring passwords or app store installs stops older aunts, uncles, and grandparents cold in a living room. Contributors simply enter their first name to browse, verify, and add memories—while batch media uploads sit cleanly behind a separate passphrase gate.

03 // GENEALOGICAL INTEGRITY

Preserving Disagreement Rather Than Overwriting

When two siblings remember different years or faces in a photo, both guesses are vital historical clues. Omitting unique constraints per contributor lets multiple relatives save memories side-by-side tagged as "pretty sure" or "just guessing", with existing notes displayed above the form for corroboration.

04 // DESIGN DISCOVERY

How Reunion Readability Sparked Neo-Brutalism

Polishing this utility-first interface around IBM Plex Mono, a strict 16px minimum font floor, sharp 0px radii, high-contrast monochrome surfaces, and oversized 52px buttons let historical photos stand as the sole source of color—and sparked my love for Neo-Brutalism.

UUID-Anchored Archive Safety

Photos never touch private iCloud credentials online. Records key on immutable Apple Photos UUIDs (or randomUUID() on browser uploads), preventing classic IMG_0001.JPG collisions and enabling future round-trip metadata write-back.

Four-Table Relational Core

Models photos, multi-author captions (with SQL-checked confidence labels), composite-key skips via INSERT OR IGNORE so skipping unfamiliar faces never blocks anyone else, and append-only caption_history.

Zero Router Bloat on Frontend

Instead of dragging in heavy state managers or routing dependencies, the React SPA coordinates sequential captioning, "My Notes", 60-thumb pagination, and batch downloads cleanly with return-position tracking so light-table browsing never loses your place.

03 // Hardening & Pipeline Highlights

Built for Reunion Wi-Fi, Safety & Longevity

01

Non-Destructive Edit Auditing via Atomic SQL Transactions

Allowing inline edits on "My Notes" creates risk if a relative accidentally erases an earlier story. Refactoring caption updates to copy the existing row into caption_history inside an explicit BEGIN / COMMIT / ROLLBACK SQLite transaction ensures past memories are always recoverable from a clean on-demand drawer.

02

Zero-Compile Portability Using Native node:sqlite

Because native C++ bindings (better-sqlite3) failed V8 compilation on Chris's Node v26 runtime, migrating to Node's built-in node:sqlite (DatabaseSync) paired with WAL concurrency eliminated native build chains completely across macOS development and Linux hosting.

03

Hybrid Media Pipeline: iCloud Fallback + EXIF Auto-Rotation

Because iCloud-optimized Macs frequently mark non-destructive edits without caching rendered files locally, the Python osxphotos extractor gracefully falls back to unedited originals instead of skipping precious photos. Meanwhile, browser uploads on Windows, Android, or iOS pass through sharp().rotate() to bake smartphone EXIF orientation directly into standardized 1920px views and 400px grid thumbnails.

04

Streaming Portable Exports & WCAG Contrast Hardening

Selectively exporting albums pipes directly into HTTP responses via streaming archiver ZIP generation without buffering large photo sets in memory. During UI hardening, replacing faded opacity: 0.35 disabled styling with opaque neutral grey (opacity: 1) preserved strict WCAG legibility for every family member.

04 // Technical Decisions Summary

Constraints & Architectural Solutions

Challenge Context & Constraint Engineering Decision
Node v26 SQLite Builds Native C++ addons failed against modern Node v26 headers across dev environments. Adopted built-in node:sqlite (DatabaseSync) with WAL concurrency—zero native compile steps.
Uncached iCloud Edits iCloud Macs flag edited images whose rendered outputs may not exist locally. Built a fallback path in Python osxphotos exporting unedited originals rather than dropping photos.
Non-Mac Relatives Family members on Android, Windows, or phones couldn't use local macOS export scripts. Engineered cross-platform browser upload ingestion using multer + sharp with instant SQLite registration.
Multi-Author Memory Edits Inline edits risked losing earlier nuances; conflicting stories needed equal visibility. Logged immutable snapshots into caption_history inside transactions and displayed peer notes above forms.
Long-Term Family Custody Oral history must outlive any single web server or framework. Built streaming collision-safe ZIP archives bundling JPEGs, human-readable .txt sidecars, and JSON manifests.
