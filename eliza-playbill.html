01 // Problem & Creative Reframing

Turning Blank-Card Paralysis Into Information Architecture

01 // THE CHALLENGE

Why Physical Cards Fell Short

I wanted to make an unforgettable 26th birthday card for my New York & Broadway Playbill–collecting partner—our first birthday celebrated together. Hand-lettering, picking stationery colors from scratch, and facing an empty white page made creative work stall out fast.

02 // DOMAIN MODELING

Using Broadway Playbill Grammar as a Spec

Instead of fighting a blank canvas, I treated software as my artistic medium. Locking the visual grammar to Playbill yellow (#fde513), crisp 1px black rules, and an Oswald + Lora + Playfair Display type hierarchy eliminated guesswork instantly.

03 // COLLABORATIVE STORYTELLING

Close Friends Disguised as Musical Numbers

Rather than packing every feeling into a single block of prose, friends became cast members performing Act I & Act II songs titled after Eliza's traits (Whimsical, Indescribable, Genuine, Assertive, Extraordinary, Thoughtful, Lighthearted)—opening heartfelt tributes when tapped.

04 // RAPID DATA UPDATES

Zero-Stress Sprint Edits via Decoupled JSON

With active building compressed into a focused ~30-hour birthday sprint, friend messages kept arriving up to the morning of the surprise. Storing tributes cleanly inside static messages.json meant cast and message changes took seconds with zero layout risk.

03 // Engineering Highlights

Zero-Library Precision Mechanics

01

Consolidating Multi-Page Files Into an Instant Booklet

Early sketches separated views across standalone HTML documents, which broke booklet immersion with full-page flashes and repeatedly discarded fetched tribute state. Consolidating all seven scenes into one horizontal track eliminated page transitions and kept startup fetching to a single request.

02

Tap vs. Swipe Disambiguation & Scroll Dead-Zone Filtering

Supporting horizontal swipes, vertical reading scroll, and clickable song/photo elements on one mobile screen requires guarding against zero-drag taps. Because simple taps never trigger touchmove (leaving currentX === 0), checking startX !== 0 && currentX !== 0 and requiring a 50px swipe threshold guarantees intentional flips without fighting vertical reading.

03

Race-Condition-Safe Cross-Fade Carousel & XSS-Safe Modals

For the MemoryMix ad carousel, assigning carouselImg.onload before updating carouselImg.src eliminates a classic browser-cache race condition where cached JPEGs complete synchronously and stall at opacity: 0. Meanwhile, assigning textContent in the singleton song modal renders emojis and punctuation cleanly with zero HTML injection exposure.

touch_swipe_guard.js 
const swipeThreshold = 50;

appContainer.addEventListener('touchend', () => {
  if (startX !== 0 && currentX !== 0) {
    const deltaX = currentX - startX;
    if (Math.abs(deltaX) > swipeThreshold) {
      if (deltaX < 0 && currentPageIndex < totalPages - 1) {
        currentPageIndex++;
      } else if (deltaX > 0 && currentPageIndex > 0) {
        currentPageIndex--;
      }
      pageTrack.style.transform = `translateX(-${currentPageIndex * 100}vw)`;
    }
  }
  startX = 0; currentX = 0;
});
carousel_crossfade.js 
carouselImg.style.transition = 'opacity 0.3s ease-in-out';

carouselImg.addEventListener('click', () => {
  carouselImg.style.opacity = 0;
  setTimeout(() => {
    currentImageIndex = (currentImageIndex + 1) % images.length;
    // Bind onload before src assignment to survive browser cache hits
    carouselImg.onload = () => {
      carouselImg.style.opacity = 1;
    };
    carouselImg.src = images[currentImageIndex];
  }, 300);
});
Post-Launch Retrospective // Edge Cases & Desktop Parity

What I Would Harden Next for Production Reuse

Because this gift shipped in a 30-hour sprint specifically for Eliza's phone screen, a subsequent iteration for broad desktop users would add three structural upgrades directly applied in my later portfolio UI work: explicit ArrowLeft / ArrowRight keyboard & on-screen button navigation, timer cancellation (clearTimeout / transitionend guards) against rapid multi-taps on the photo carousel, and percentage-based track offsets avoiding scrollbar width drift.

It proved that the exact same instinct behind enterprise architecture—modularity, clear state boundaries, clean constraints—makes personal coding endlessly fun.
