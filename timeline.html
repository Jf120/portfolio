src/lib/processImage.ts — Lazy HEIC Decoder 
async function normalizeToProcessableFile(file: File): Promise<File> {
  if (!isHeicFile(file)) return file;

  // Dynamic import keeps 1.35 MB decoder out of the 584 KB main bundle
  const { default: heic2any } = await import('heic2any');
  const convertedBlob = await heic2any({
    blob: file,
    toType: 'image/jpeg',
    quality: 0.8,
  });

  const blob = Array.isArray(convertedBlob) ? convertedBlob[0] : convertedBlob;
  return new File([blob], file.name.replace(/\.(heic|heif)$/i, '.jpg'), {
    type: 'image/jpeg',
    lastModified: file.lastModified,
  });
}
src/lib/utils.ts — Local Timezone Guard 
// Prevents new Date("2022-09-06") UTC midnight off-by-one day shift
export function parseLocalDateInput(dateValue: string, preserveTimeFrom?: number): number {
  const match = dateValue.match(/^(\d{4})-(\d{2})-(\d{2})$/);
  if (!match) return fallbackOrNow(preserveTimeFrom);

  const year = Number(match[1]);
  const month = Number(match[2]) - 1;
  const day = Number(match[3]);

  // Anchors to local noon (12:00:00) so Western timezones never slip back 1 day
  return new Date(year, month, day, 12, 0, 0).getTime();
}
03 // Hard Problems Solved

Engineering Highlights & Browser Edge Cases

01

Eliminating UTC Midnight Off-by-One Date Shifts

Native <input type="date"> controls emit strings like "2022-09-06". Passing that string to new Date("2022-09-06") parses as UTC midnight, shifting displayed dates backward by one full day (September 5, 2022) across Western Hemisphere timezones. Writing parseLocalDateInput to split YYYY-MM-DD and construct a local Date at noon (preserving existing time-of-day when editing) guarantees exact calendar dates everywhere.

02

StrictMode-Safe Blob ObjectURL Lifecycle Management

Creating preview URLs with URL.createObjectURL(blob) inside useEffect and calling setState synchronously triggers cascading renders and risks leaking or prematurely revoking URLs during React 19 StrictMode double mounts. A custom useObjectUrl hook defers creation to a microtask guarded by a cancelled flag, pairs each URL with its exact Blob reference, and deterministically revokes it on cleanup.

03

Cutting Initial Bundle Weight by ~70% While Preserving EXIF & HEIC

Bundling heic2any eagerly bloated the initial JS payload to 1.93 MB, while standard image compressors stripped EXIF metadata before timestamps or GPS coordinates could be read. Reading EXIF/DMS coordinates prior to Web Worker compression and switching heic2any to a dynamic import('heic2any') cut the main bundle to 584 KB (188 KB gzipped).
