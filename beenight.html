gameEngine.ts — Config Schema Guard 
const ALLOWED_CONFIG_KEYS = new Set(Object.keys(DEFAULT_GAME_CONFIG));

// Prevents imported JSON or WebSocket payloads from smuggling protected keys
export function pickKnownConfigKeys(patch: unknown): Partial<GameConfig> {
  if (!patch || typeof patch !== 'object') return {};
  return Object.fromEntries(
    Object.entries(patch as Record<string, unknown>)
      .filter(([key]) => ALLOWED_CONFIG_KEYS.has(key))
  ) as Partial<GameConfig>;
}

03 // Hard Problems Solved

Engineering Highlights

01

Pure-TypeScript SHA-256 for Non-HTTPS LAN Pairing

When hosts test or run sessions over local Wi-Fi IPs, browsers mark non-HTTPS origins as insecure contexts and disable window.crypto.subtle. Implementing a standalone FIPS 180-4 SHA-256 digest in pure TypeScript lets salted capability-token QR links (?room=BEE-XXXX&auth=<hash>) authenticate seamlessly across both LAN HTTP and public HTTPS.

02

Fitting 50+ Contestant Avatars Under localStorage Quotas

Uploading 5MB guest selfies directly into a 5MB browser quota immediately crashes with QuotaExceededError. A client-side HTML5 Canvas compressor crops and encodes portraits into 256×256 JPEG data URLs (~15–25KB each, >99% smaller), paired with three focal coordinates (photoFocusX, photoFocusY, photoScale) driving objectPosition and transformOrigin across mobile badges and 16:9 TV spotlights.

03

Decluttering the Live Host View via Strict Stage Projection

In front of a room full of friends, showing pre-game roster tools beside active round buttons invites accidental clicks. Refactoring the Host Remote into a strict projection of gameState.stage keeps only relevant controls visible per phase, while keeping the app deployable at zero database cost.
